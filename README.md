# 時計修理工房（Watch Repair Workshop）

時計修理工房を舞台にした、一人称視点の3Dシミュレーションゲームです。ブラウザで動きます。
お客さんから時計を預かり、本物の時計職人と同じ手順で修理します。

> **いまの段階：第1段階**（工房を歩ける／作業台で作業モード／クォーツ腕時計の電池交換）

---

## 1. 遊ぶ準備（最初の1回だけ）

### ① Node.js を入れる
[https://nodejs.org/](https://nodejs.org/) から **LTS版**（推奨版）をダウンロードしてインストールします。
入ったかどうかは、ターミナルで次のコマンドを打つと確かめられます（`v20` 以上の数字が出ればOK）。

```bash
node -v
```

> ターミナルの開き方
> - Windows：スタートメニューで「PowerShell」と検索して開く
> - Mac：「アプリケーション → ユーティリティ → ターミナル」

### ② このプロジェクトをダウンロードする
GitHub のページで緑色の「Code」ボタン →「Download ZIP」でダウンロードして展開します。
`git` を使える場合は次のコマンドでもOKです。

```bash
git clone https://github.com/hura04/WR-games.git
```

### ③ フォルダに移動して、必要な部品をインストール
展開したフォルダ（`package.json` が入っているフォルダ）にターミナルで移動します。

```bash
cd WR-games
```

```bash
npm install
```

`node_modules` というフォルダができれば成功です（数十秒かかります）。

---

## 2. 起動する（毎回）

```bash
npm run dev
```

ブラウザが自動で開きます。開かないときは、ターミナルに表示された `http://localhost:5173/` をブラウザ（Chrome 推奨）で開いてください。
終了するときは、ターミナルで `Ctrl + C` を押します。

## 3. 遊び方

### 工房を歩く
| 操作 | 内容 |
|---|---|
| W A S D | 移動 |
| マウス | 見回す |
| E | 調べる・話す（画面中央の点を対象に向ける） |
| Esc | 一時停止（ガイド設定・セーブ消去もここ） |

### 作業台（作業モード）
| 操作 | 内容 |
|---|---|
| 1〜0 キー / 下のボタン | 道具を持ち替える |
| 左クリック | 持っている道具で部品を使う |
| 右ドラッグ | 時計を回す |
| F | 時計を裏返す |
| ホイール | ズーム |
| L | ルーペ（マウスの位置を4倍に拡大） |
| H | 次の工程の解説 |
| G | 手順ガイドの表示／非表示（上級モード） |
| X | 席を立つ |

### 1件の流れ
1. 受付カウンターで **E** → お客さんの話を聞く
2. 受付で時計を診断する（秒針の動き、外観の傷の記録など）
3. 見積もりを作って引き受ける（パッキン交換を付けるかどうかも自分で判断）
4. 奥の作業台で **E** → 作業モードで電池交換をする
5. 受付カウンターで **E** → 返却。仕上がりが★1〜5で評価され、報酬がもらえる（自動セーブ）

**失敗の例**：金属ピンセットで電池をつまむ → ショート／力を入れすぎる → 傷・風防の破損／
受付で傷を記録しない → お客さんに疑われる、など。

## 4. ファイル構成

```
WR-games/
├─ README.md              ← このファイル
├─ index.html             ← 画面の骨組み（HTML）
├─ package.json           ← 使っているライブラリと起動コマンドの設定
├─ src/
│  ├─ main.js             ← ゲームの入口
│  ├─ style.css           ← 画面のデザイン
│  ├─ data/               ★ ゲームの中身のデータ（ここを書き換えれば増やせる）
│  │  ├─ tools.js            道具
│  │  ├─ consumables.js      消耗品（電池・パッキン）
│  │  ├─ watches.js          時計の機種（寸法から3Dモデルが自動で作られる）
│  │  ├─ parts.js            部品の名前と説明
│  │  ├─ customers.js        お客さんとセリフ
│  │  ├─ diagnosis.js        受付での診断項目
│  │  ├─ services.js         見積もりの作業メニューと料金
│  │  ├─ failures.js         失敗の種類と減点
│  │  └─ procedures/         作業工程（1作業 = 1ファイル）
│  │     ├─ index.js            工程の一覧
│  │     └─ quartz_battery.js   クォーツ電池交換の全工程
│  ├─ core/               ゲーム全体の管理（Game.js）、セーブ（state.js）、アニメーション
│  ├─ world/              工房の部屋（Workshop.js）と一人称移動（PlayerController.js）
│  ├─ bench/              作業モード（BenchMode.js）と手元の机（BenchScene.js）
│  ├─ watch/              時計の3Dモデルを作るコード
│  ├─ procedure/          工程を進めるルール（ProcedureRunner.js）、評価（scoring.js）
│  │  └─ minigames/       力加減・角度・手ブレ・適量・測定・選択のミニゲーム
│  ├─ sim/                時計の内部状態と測定値（電池電圧など）
│  └─ ui/                 お知らせ表示、受付の会話・見積もり・評価画面
├─ tests/                 自動テスト（npm test で実行）
└─ docs/                  設計メモ
```

### データの足し方の例
- **お客さんを増やす**：`src/data/customers.js` の配列に1人分コピーして書き換える
- **時計の色違いを増やす**：`src/data/watches.js` に1件追加して、`customers.js` の `watch` でそのidを指定
- **工程の解説を直す**：`src/data/procedures/quartz_battery.js` の `explain` を書き換える
- **難しさを変える**：工程の `zoneMin` / `zoneMax`（力加減の緑の範囲）や `corridor`（手ブレの通路の幅）を変える

ファイルを保存すると、`npm run dev` 中のブラウザは自動で更新されます。
