# 時計修理工房（Watch Repair Workshop）

時計修理工房を舞台にした、一人称視点の3Dシミュレーションゲームです。ブラウザで動きます。
お客さんから時計を預かり、本物の時計職人と同じ手順で修理します。

> **いまの段階：第3段階**（お金・ショップ端末・道具のグレードアップ・消耗品の仕入れ・1日の締め）

---

## 1. 遊ぶ準備（最初の1回だけ）

### ① Node.js を入れる
[https://nodejs.org/](https://nodejs.org/) から **LTS版**（推奨版）をダウンロードしてインストールします。
入ったかどうかは、ターミナルで次のコマンドを打つと確かめられます（`v20` 以上の数字が出ればOK）。

```bash
node -v
```

> ターミナルの開き方
> - Windows：スタートメニューで「PowerShell」と検索して開く
> - Mac：「アプリケーション → ユーティリティ → ターミナル」

### ② このプロジェクトをダウンロードする
GitHub のページで緑色の「Code」ボタン →「Download ZIP」でダウンロードして展開します。
`git` を使える場合は次のコマンドでもOKです。

```bash
git clone https://github.com/hura04/WR-games.git
```

### ③ フォルダに移動して、必要な部品をインストール
展開したフォルダ（`package.json` が入っているフォルダ）にターミナルで移動します。

```bash
cd WR-games
```

```bash
npm install
```

`node_modules` というフォルダができれば成功です（数十秒かかります）。

---

## 2. 起動する（毎回）

```bash
npm run dev
```

ブラウザが自動で開きます。開かないときは、ターミナルに表示された `http://localhost:5173/` をブラウザ（Chrome 推奨）で開いてください。
終了するときは、ターミナルで `Ctrl + C` を押します。

## 3. 遊び方

### 操作方法の選び方
タイトル画面と一時停止画面の「操作方法」で選べます（自動にしておくと端末に合わせます）。
- **マウス・キーボード**：パソコン向け。ノートPCのタッチパッドもこちら
- **タッチ**：iPad などのタブレット向け

### 工房を歩く
| 操作 | マウス | タッチ |
|---|---|---|
| 移動 | W A S D | 左下のスティック |
| 見回す | マウス | 画面をドラッグ |
| 調べる・話す | E | 右下の［調べる］ボタン |
| 一時停止（設定） | Esc | 右上の ☰ |

### 作業台（作業モード）
| 操作 | マウス・タッチパッド | タッチ |
|---|---|---|
| 道具を持ち替える | 下のホットバー（10マス）をクリック／1〜0キー（テンキーも可） | ホットバーをタップ |
| ホットバーにない道具を使う | ［道具箱］ボタン／Tab キー → 道具を選ぶ（ホットバーにも入る） | ［道具箱］→ 道具をタップ |
| 部品に道具を使う | 部品をクリック | 部品をタップ → もう一度タップ |
| 時計を回す | 右ドラッグ、何もない所を左ドラッグ | 何もない所をドラッグ、2本指ドラッグ |
| ズーム | ホイール、ピンチ | ピンチ、右のボタン（＋−） |
| 表裏を返す | F | 右の［表裏］ |
| ルーペ（4倍） | L | 右の［ルーペ］ |
| 解説 / ガイド切替 | H / G | 右の［解説］［ガイド］ |
| 席を立つ | X | 右の［席を立つ］ |

### 1件の流れ
1. 入口からお客さんが入ってきてカウンターに来たら、受付で **調べる** → 話を聞く
2. 受付で時計を診断する（クォーツ：秒針・外観など／機械式：**タイムグラファー**で歩度・振り角・片振りを測る）
3. 見積もりを作って引き受ける（パッキン交換・ゼンマイ交換を付けるかも自分で判断）
4. 作業台で作業する
   - クォーツ：電池交換（13工程）
   - 機械式：オーバーホール（約60工程）。途中で**洗浄機**まで歩いて部品を洗い、また作業台に戻る
5. 受付で返却。仕上がりが★1〜5で評価され、報酬がもらえる（自動セーブ）
6. 右奥の **ショップ端末（パソコン）** で、お金を使う
   - **消耗品**：電池・パッキン・ゼンマイ・油を仕入れる（すぐ届く）。在庫が切れると、その作業ができません
   - **道具**：道具を「一式」でグレードアップ（入門用 → 中級 → プロ用）。手ブレが減る、ルーペの倍率が上がる、油の量を合わせやすくなる。プロ用は評判が必要
   - **帳簿**：その日のお金の出入り
   - **営業終了**：家賃・光熱費（1日1,000円）を払って次の日へ。返却期限は日付で決まるので、日を進めすぎると報酬が減ります

> 見積もり画面には「使う部品」の在庫と仕入れ値が出ます。足りないときは、引き受けたあとショップ端末で仕入れましょう。

### 機械式オーバーホールで気をつけること（失敗の例）
- 保護シートなしで針を外す → 文字盤に傷
- **ゼンマイの力を抜かずに**アンクルを外す → 歯車のほぞが折れる
- ドライバーのサイズ違い → ネジ溝をつぶす・受けに傷
- 丸穴車のネジは**逆ネジ**。反対に回すとネジ山を壊す
- 油の種類・量の間違い → 振り角が上がらない
- 洗浄の順番（洗浄液→すすぎ→すすぎ→乾燥）を間違える → 汚れが残る
- パッキンを替えない・裏蓋の締め込み不足 → 防水テストで漏れ

最後のタイムグラファー測定（歩度 0〜+5秒/日、振り角 270°以上、片振り 0.6ms以下が目安）も評価に入ります。

## 4. ファイル構成

```
WR-games/
├─ README.md              ← このファイル
├─ index.html             ← 画面の骨組み（HTML）
├─ preview.html           ← 開発用：時計の3Dモデルを確認するページ（/preview.html）
├─ package.json           ← 使っているライブラリと起動コマンドの設定
├─ src/
│  ├─ main.js             ← ゲームの入口
│  ├─ style.css           ← 画面のデザイン
│  ├─ data/               ★ ゲームの中身のデータ（ここを書き換えれば増やせる）
│  │  ├─ tools.js            道具
│  │  ├─ consumables.js      消耗品（電池・パッキン・ゼンマイ・油）と値段
│  │  ├─ upgrades.js         道具のグレード（値段・必要な評判・手ブレ・ルーペ倍率など）
│  │  ├─ watches.js          時計の機種（寸法から3Dモデルが自動で作られる）
│  │  ├─ movements.js        機械式ムーブメントの部品配置（歯車・受け・テンプの位置）
│  │  ├─ oils.js             時計油・グリスの種類
│  │  ├─ parts.js            部品の名前と説明
│  │  ├─ customers.js        お客さんとセリフ
│  │  ├─ diagnosis.js        受付での診断項目
│  │  ├─ services.js         見積もりの作業メニューと料金
│  │  ├─ failures.js         失敗の種類と減点
│  │  └─ procedures/         作業工程（1作業 = 1ファイル）
│  │     ├─ index.js            工程の一覧
│  │     ├─ quartz_battery.js        クォーツ電池交換の全工程
│  │     └─ mechanical_overhaul.js   機械式オーバーホールの全工程
│  ├─ core/               ゲーム全体の管理（Game.js）、セーブ（state.js）、お金のルール（economy.js）
│  ├─ world/              工房の部屋（Workshop.js）、お客さん（Person.js）、一人称移動（PlayerController.js）
│  ├─ bench/              作業モード（BenchMode.js）と手元の机（BenchScene.js）
│  ├─ watch/              時計の3Dモデルを作るコード
│  ├─ procedure/          工程を進めるルール（ProcedureRunner.js）、評価（scoring.js）
│  │  └─ minigames/       力加減・角度・手ブレ・適量・測定・選択・注油・タイムグラファー調整・洗浄・防水テストなど
│  ├─ sim/                時計の内部状態と測定値（電池電圧、振り角・歩度・片振りなど）
│  └─ ui/                 お知らせ表示、受付の会話・見積もり・評価画面、ショップ端末（Shop.js）、道具の絵（toolIcons.js）
├─ tests/                 自動テスト（npm test で実行）
└─ docs/                  設計メモ
```

### データの足し方の例
- **お客さんを増やす**：`src/data/customers.js` の配列に1人分コピーして書き換える
- **時計の色違いを増やす**：`src/data/watches.js` に1件追加して、`customers.js` の `watch` でそのidを指定
- **工程の解説を直す**：`src/data/procedures/quartz_battery.js` の `explain` を書き換える
- **道具や消耗品の値段を変える**：`src/data/upgrades.js`（道具のグレード）と `src/data/consumables.js`（消耗品）の `price`
- **難しさを変える**：工程の `zoneMin` / `zoneMax`（力加減の緑の範囲）や `corridor`（手ブレの通路の幅）を変える
- **新しい時計の見た目を確認する**：`npm run dev` 中に `http://localhost:5173/preview.html` を開くと、watches.js の時計をぐるぐる回して見られます

ファイルを保存すると、`npm run dev` 中のブラウザは自動で更新されます。
